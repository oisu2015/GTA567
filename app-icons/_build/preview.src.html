本次改版：品牌符号改为「强」

2026-11-08 图标定稿，当前 APK 为 v4.6（2026-11-16）。原设计语言（深蓝渐变、白字、青色播放三角、slogan）全部保留，仅把核心符号由「致」换成「强」，并针对新字重排版面。品牌名仍为「致强视频」。

改动点说明结果
符号换字原三款图标统一为「致」字三款 PNG / SVG、各密度资源、焦点态、变体全量重出，统一为「强」字
字号过大「强」字笔画更密、外框更方；沿用旧字号会顶满画布，横版还会挤到品牌名三款字号统一下调一档（0.45 / 0.41 / 0.42），四周留白恢复
播放三角压笔画旧坐标下青三角与「强」右下捺笔相撞，3:1 版甚至叠在字上三角整体外移并缩小，落在右下留白区，三款均不压字
矢量源与位图不一致旧生成脚本把符号字硬编码进 SVG，改 PNG 时 SVG 没跟着变SVG 文字节点改为读取同一个 GLYPH 常量，改一处整套同步
输出路径写死脚本 ROOT 曾指向上级 DuShetv/app-icons，容易生成到错误目录改为按脚本所在位置推导，放到哪套 app-icons 就重出哪套
历史修正一并保留：汉字用微软雅黑 Bold 真实字体渲染（修正 AI 错笔画与幻觉）、去除生成水印、透明底改为不透明深蓝底、严格 1:1 / 16:9 / 3:1 规格与多密度档、3:1 版 Logo 与品牌名留 3% 呼吸区。

接入 Android TV

关键一点：640×360 正好是 Android TV 官方 Banner 规范——Leanback Launcher 在横版槽位读的是 android:banner（320×180 dp，xhdpi 下即 640×360 px），不是 android:icon。原工程用的是系统图库图标且完全没有 banner，已一并修好。


android:icon="@mipmap/ic_launcher"
    android:banner="@drawable/banner"   
    ... >
    android:name=".MainActivity"
        android:banner="@drawable/banner"   
        ... />
已写入工程 res/ 的资源：mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher.png（48/72/96/144/192）、drawable-{m,h,xh,xxh}dpi/banner.png（320×180 / 480×270 / 640×360 / 960×540）、drawable-nodpi/zq_wide_960x320.png。已全部同步进工程 res/，自 v4.4 起、当前 v4.6 (code 62) 均打进 APK。

几点建议

  • 焦点态别用静态图。 本交付里的 *_focus.png 是设计参考，正式实现请交给代码：Launcher 的放大由系统做，应用内沿用项目已有的 focusZoom() / selector。若图片和代码同时放大，会出现双重缩放、边缘发虚。
  • 默认版不带 NEW 角标。 角标会过时且缩小后糊，已单独放 variants/zq_wide_960x320_new.png，需要时再启用。超宽版右侧留白是刻意留给动态控件的。
  • slogan 在小尺寸降级。 480×160 及以下的横版建议省略「好片随心看」；当前 640×360 主档保留，字号约 26px，1080p 下仍可读。
  • 正方形留了 10% 安全边距。 电视桌面常自带圆角遮罩，会二次裁切；另备直角版 variants/zq_square_512_nocorner.png，将来做 Android 8+ Adaptive Icon 时可直接当背景层（108dp 画布、中心 66dp 安全区）。
  • 浅色版不建议做。 电视 UI 恒为深色，图标已有不透明底，深、浅壁纸都验证可读；再维护一套浅色图标收益很低。
